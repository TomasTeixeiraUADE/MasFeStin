Sistema de Gestión Veterinaria - TPO POO


Descripción del Proyecto:

Este proyecto corresponde al Trabajo Práctico Obligatorio (TPO) de la materia Programación Orientada a Objetos. 
Desarrolla la gestión de una clínica veterinaria, incluyendo el registro de pacientes y dueños, atención médica,
control de stock, facturación con múltiples formas de pago y recordatorios automáticos de refuerzos de vacunación.
